# Actual Intelligence — temporary preview

A clickable preview of **Actual Intelligence** (Project Y): a marketplace with an originality guarantee for digital art, games, and code, and a secondary category for physical crafts. Built so Kage and co-founders can share how the shop might look and work, including over WhatsApp.

The core promise is that the work is truly the creator’s own, from composition to finished product: no AI generation, no painting over existing pictures, no elements of other artists’ work. Creators show every step of the process. For visual work, a reverse image search should only find things that look similar, never the same.

This is not a live company or shop. Sample listings and makers are example data. Nothing can be bought, and the interest forms do not send or store anything.
